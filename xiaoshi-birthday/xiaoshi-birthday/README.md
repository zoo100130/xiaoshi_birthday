# 小士十八歲生日

從台灣寄到海南的生日網頁。這份是自己在電腦上看的本地版。

## 資料夾裡有什麼

```
xiaoshi-birthday/
├── index.html               整個網頁（版面、樣式、互動程式都在這裡）
├── images/                  貼圖檔案
│   ├── sticker1.png
│   └── sticker2~4.gif
└── config/
    ├── stickers.js          每張貼圖的位置、大小、角度
    └── wishes-layout.js     十句祝福語各自移動了多少
```

## 怎麼打開

直接用瀏覽器（Chrome、Edge、Safari）打開 `index.html`。三個資料夾要放在一起，圖片才讀得到。

## 位置是怎麼運作的

網頁打開時，會先載入 `config` 裡的兩個設定檔，再依照裡面的數字把東西擺好。

**貼圖（stickers.js）**
- `x`：水平位置，0 是最左邊，0.5 是正中間，1 是最右邊。用比例而不是像素，所以換成手機的窄螢幕，貼圖也會跟著等比例移動。
- `y`：從網頁最上面往下算的像素。
- `w`：寬度（像素）。
- `r`：旋轉角度。
- `f`：`true` 加拍立得白框，`false` 是去背貼紙。
- `m`：`true` 去掉圖片本身的白底。原理是 CSS 的 `mix-blend-mode: multiply`，白色乘上底色就等於底色，所以白色看起來像透明。

**祝福語（wishes-layout.js）**
每句祝福語先照原本的排法放好，再用 CSS 的 `translate` 從原位挪過去。`x` 一樣是比例，`y` 是像素，負數代表往上。

## 用拖曳的方式調位置

1. 用瀏覽器打開 `index.html#edit`（網址最後加上 `#edit`）。
2. 右下角會出現工具列，祝福語上方也會出現「開始排版」按鈕。
3. 照片直接拖。按「整理圖片」叫出縮放、旋轉、框、去白的小按鈕。
4. 祝福語要先按「開始排版」才拖得動。
5. 排好後按「複製設定檔」，把複製到的內容貼進 `config` 裡對應的兩個檔案、存檔。
6. 重新整理網頁，新的位置就固定了。

## 想加新圖片

1. 把圖片放進 `images` 資料夾。
2. 在 `config/stickers.js` 的清單裡加一行，例如：
   `{ file: "我的新圖.png", x: 0.5, y: 800, w: 200, r: 0, f: false },`
3. 重新整理網頁，再用 `#edit` 模式把它拖到想要的位置。

## 想改文字

在 `index.html` 裡搜尋：
- 祝福語：`class="note"`
- 給小士的信：`給小士`
- 角色台詞：`const LINES=`
- 泡泡裡的字：`const POPS=`

## 注意

`images` 裡有些是有版權的角色圖，這份只適合自己在電腦上看，不要上傳到 GitHub 或其他公開網站。
